Bem-vindo ao CSS

O CSS (Cascading Style Sheets) é uma linguagem de estilo usada para descrever a apresentação de um documento escrito em HTML.

Sobre o CSS

Linguagem responsável por definir a aparência visual e organização dos elementos na tela.

Como aplicar o CSS?

Para o CSS, temos três abordagens:

  • Inline:
  • Internal:
  • External:

O que da pra fazer com CSS

O CSS não serve para apenas colocar cor na página. Ele controla:

  • cores
  • fontes
  • tamanhos
  • sombra
  • bordas
  • posicionamento
  • responsividade
  • animações
  • transições

Aplicando CSS Inline

Nessa abordagem, o CSS é colocado diretamente nos elementos HTML através do atribuito style.

Exemplo:

<p style="color: blue; font-size: 16px;">Este parágrafo tem cor azul e fonte de 16px.</p>

Este parágrafo tem cor azul e fonte de 16px.

Aplicando CSS Internal

Nessa abordagem, o CSS é colocado dentro da tag <style> no head do documento HTML.

Aplicando CSS External

Nessa abordagem, o CSS é colocado em um arquivo separado com a extensão .css e importado para o documento HTML através da tag <link>.

Para conectar o arquivo CSS ao documento HTML, basta usar a tag <link>.
